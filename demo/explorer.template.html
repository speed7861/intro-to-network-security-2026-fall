How the numbers are computed
  • Each case targets one rule. A tool "detects" a case if it raises an alert for that rule in that case's file. Misuse cases score TP or FN, secure cases score FP or TN.
  • Precision = TP / (TP + FP). Recall = TP / (TP + FN). F-β weights recall β times as much as precision.
  • Confidence intervals come from a percentile bootstrap: the selected cases are resampled with replacement, and the metric is recomputed for each resample. The seed makes this repeatable.
  • The significance test is an exact McNemar test on the misuse cases. It only looks at cases where exactly one tool is right, so it compares the two tools on the same cases.
